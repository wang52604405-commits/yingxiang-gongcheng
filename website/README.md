# 工程影像管理平台宣传网站

这是工程影像管理平台的正式宣传网站源码，面向水利、房建、市政、电力四大专业。

## 目录

- `index.html`：首页
- `product.html`：产品介绍
- `usage.html`：使用说明
- `download.html`：下载页
- `contact.html`：联系页
- `assets/`：网站样式、脚本、界面截图和现场照片
- `tutorial/工程影像管理平台-使用教程.docx`：使用教程源文件
- `site-content.json`：站点名称、下载地址和当前对外的产品数字

## 维护入口

优先修改 `site-content.json` 中的站点名称、小程序介绍、专业列表和下载链接；页面结构和样式分别在各 HTML 文件及 `assets/style.css` 中维护。交互动效集中在 `assets/site.js`，并兼容系统“减少动态效果”设置。

发布时先上传到服务器临时目录并校验，再覆盖站点页面。安装包仍留在服务器的 `download/` 里，这次发布只更新同目录下的使用教程，不删除安装包。页面上的版本号在发布时读取更新通道里的版本；读不到就不写版本号。
