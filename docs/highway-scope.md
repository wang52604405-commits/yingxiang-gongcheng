# 公路土建专业支持范围

依据 JTG F80/1—2017 第 1.0.2、3.1.1～3.1.3 条及附录 A，适用于各等级公路新建、改扩建土建工程。工程质量层级为单位、分部、分项；合同段是管理范围。附录 A 各行条件不同：小桥及达到小桥标准的通道按座或处划分分部，涵洞、砌筑防护按路段，排水结合数量、特点与施工程序。这里用于核对项目批准划分，不由软件强制覆盖全部类型。软件分类不是法定层级，不把涵洞、排水等章节直接生成单位工程。

导入批准的工程划分，保持原名称和编码，桩号、左右幅、结构部位另列。公路模板不生成示例工程或固定长度限值。子分部仅作为有明确划分依据的项目扩展。不支持的子单位、子分项扩展会报错，不静默压平。

内部归档标识由所属工程和完整父路径生成，原码单独保存；照片流水编号与工程原码是不同字段，照片编号为兼容文件名仍使用安全字符，原工程编码在划分、界面及目录字段保留；不同父路径允许相同分项编码。同一完整路径重复报错，已存在路径跳过且不改原资料。所有导入字段先整批检查，校验失败不部分写入。不更改其他专业的存量节点或照片。

照片采集数量、方向、频次按适用专项规范、合同和批准的项目方案确定；本版不假造全国强制照片清单。照片整理包只检查文件和资料完整性，不替代检验评定、签认、验收或移交。公路整理包不应用市政 GB 55032 的强制拍摄规则或城建档案时限。

机电工程须另按 JTG 2182—2020 核定，旧 JTG F80/2—2004 已废止；养护、附属房屋不直接套本模板。未完成微信真机和 Windows 安装包验证，不宣称已经发布。

## 市政检验批兼容扩展

市政沿用各专业适用规范及批准的实际划分。新增可选检验批影像节点，不强迫所有分项创建同样检验批，也不推算批次容量或验收结论。已有分项节点和照片不迁移、不重新编号；新检验批与父分项可分别归档。检验批编号和名称成对填写，归属于明确父分项，内部归档标识与原码分开。软件保存的是影像归属，不是完整质量验收表系统。
